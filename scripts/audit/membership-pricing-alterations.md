# Membership Pricing Alterations

This file is generated by `scripts/audit/membership-pricing-apply.js`.

## Discount model

Enrollment discounts are fixed dollar amounts by membership type.

- single: $100 off enrollment
- couple: $100 off enrollment
- family: $150 off enrollment

## Family monthly adjustment rules

- If any child age is missing/invalid: use base family monthly dues only.
- Age > 17: first child +$90; additional children use 100 - (childIndex - 1) * 10.
- Age 14 to 17: +$15 per child.
- Young average discount gate: average age <= 6 and children <= 2.
- Young average discounts: 1 child = -$25, 2 child = -$15.
- Third child+ surcharge: +$20 for each child #3+ over age 4.

# js

## Layman's terms

Site-wide JavaScript. Scripts that run on multiple pages: homepage (index-page.js), maybe shared utilities. Page-specific JS often lives with the page.

## Medium understanding

Global or multi-page scripts. index-page.js for homepage behavior. May include shared helpers. Each script has a .readme (Law XI). Page-specific scripts (e.g. membership builder) live in Pages/ subdirs.

## Advanced

- **Contents:** index-page.js (+ index-page.readme)
- **Scope:** Homepage and shared behavior

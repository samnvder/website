## Logos

### South End Logo (Black/Original)
- **URL:** `https://southendclub.com/wp-content/uploads/2025/11/Original-Logo.svg`
- **Use:** Default logo on light backgrounds

### South End Logo (White)
- **URL:** `https://southendclub.com/wp-content/uploads/2025/11/Original-Logo.svg`
- **CSS Filter:** `filter: brightness(0) invert(1);` to convert black to white
- **Use:** Logo on dark backgrounds (hero sections, dark overlays)
- **Note:** Since the original logo is black SVG, use CSS filter to invert to white

## Notes

- SVG logos can be color-adjusted using CSS filters
- For white logo on dark backgrounds: `filter: brightness(0) invert(1);`
- For colored logo variations, consider creating separate SVG files with different fill colors

# racquets

## Layman's terms

Racquet sports assets: pickleball, tennis, etc. Photos for carousels and pages. Pickleball is the primary carousel source.

## Medium understanding

Racquet sport media. pickleball/ holds images and pickleball-images.md (source of truth for carousel). Build script reads markdown, propagates to HTML. Add images here; run build.

## Advanced

- **Subdirs:** pickleball/
- **Source:** pickleball/pickleball-images.md

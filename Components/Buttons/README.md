# Buttons

## Layman's terms

Clickable elements: CTAs, tour buttons, virtual tour links, floating nav. Each button type lives in its own folder. Don't edit directly—work in Dev.

## Medium understanding

Button components grouped by style/behavior. Static Buttons (tour, virtual tour), Floating Buttons (section nav, left upper CTA). Structure: `{name}.html`, `{name}.css`, `{name}.js`, `{name}-combined.html`. Thrive: use -combined for embed.

## Advanced

- **Subdirs:** Static Buttons/, Floating Buttons/ (if present)
- **Law VIII:** Separate markup, styles, behavior
- **IDs:** se-* prefix, globally unique

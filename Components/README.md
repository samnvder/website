# Components

Every reusable block on southendclub.com, and the live URL it renders on.

**This index exists because its absence caused a real failure.** The homepage
youth camp banner lived in the repo the whole time, filed under
`Website/Pages/youth-programs/` because that is what it *links to*. There was no
place to look that would have shown it existed, so it was rebuilt from a pasted
copy of the rendered page. If you add a block and do not add a row here, the
next person has the same problem.

Render counts measured 2026-08-18 against all 20 live pages. Regenerate with
Phase 1 of [handoffs/component-structure-reorg.md](../handoffs/component-structure-reorg.md).

## The two rules

> **Rule A — "renders on", never "relates to".** A block is filed by the page it
> *renders on*, never the page it links to or the topic it advertises.
>
> **Rule A-bis — absent is not automatically dead.** A block on no live page may
> be dormant. **Absent + a known seasonal window** → file by *intended* page and
> record the window below. **Absent + no window + no owner** → `Archive/`.
>
> **Rule B — the 2+ threshold for `Shared/`.** A block enters `Shared/` only if
> it renders on two or more pages. One page means it goes to that page's
> directory. No exceptions, or `Shared/` becomes the next dumping ground.

**Boundary with `Website/Pages/`:** `Pages/` holds whole-page Thrive source
(`* HTML.html`, page CSS). `Components/` holds blocks pasted into Thrive as their
own element. If it is a separate paste, it is a component.

## Adding or checking a block

**Before trusting an "it's not live" verdict**, verify against an identifier that
is both re-skin-proof *and* unique to the component. A class name fails when live
has been rebuilt with different wrapper markup; a third-party embed id fails when
two components share the resource. Both mistakes were made during this reorg —
see [the move list](../patches/component-structure-reorg/move-list.md).

```bash
curl -sL "https://southendclub.com/<slug>/" | grep -c "<unique-marker>"
```

**Before committing a block**, confirm it carries no output-only markup — the
`<picture>` wrappers CompressX adds, Thrive's `tve_js_placeholder`, or boolean
attributes expanded to `hidden=""`:

```bash
node scripts/convert/live-capture-to-source.js Components --report /tmp/components-audit.md
```

The `Components/` tree was clean at 17 files, 0 findings, on 2026-08-18. Note
that `npm run audit:capture` covers only `Website/Pages` and **will not catch
regressions here** — run the command above explicitly.

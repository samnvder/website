# Pickleball Carousel Component

Label + image carousel for the pickleball community section. No Pong — carousel only.

**Location:** `Components/Carousel/Pickleball/` (production components, not Create)

## Files

| File | Purpose |
|------|---------|
| **carousel-pickleball.css** | Pickleball carousel styles (Browse by Event, album grid, subheader pill). |
| **carousel-pickleball.js** | Pickleball carousel logic (Browse by Event, lightbox, shuffle). |

## Homepage Variant

The **standalone homepage carousel** lives in **Components/Index/carousel-pickleball-homepage.html**. Copy that file into your homepage.

## Embedded Usage

The racquet sports page embeds the carousel HTML directly and uses its own CSS. See `Pages/racquet-sports/` for the embedded version.

## Pickleball Pong (Separate)

Pong is **not** part of the carousel. Use **Create/games/pickleball-pong.html** — standalone, self-contained. Do not mix with carousel.

## Paths

- **From project root:** `Components/Carousel/Pickleball/`
- **Homepage carousel:** `Components/Index/carousel-pickleball-homepage.html`
- **Pong (standalone):** `Create/games/pickleball-pong.html`

# css

## Layman's terms

Global and shared styles for the site. Styles that apply across many pages (navigation, layout, typography). Page-specific CSS often lives with the page.

## Medium understanding

Site-wide CSS. May include navigation, base layout, shared components. Some pages have their own CSS files in their folder. Thrive pages may use inline styles per Law IV; this folder holds non-Thrive or shared styles.

## Advanced

- **Usage:** Linked from pages or components
- **Law IV:** Thrive uses inline styles; no `<style>` blocks in Thrive content

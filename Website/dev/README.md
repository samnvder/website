# Layman's terms

Scratch and scaffold targets for carousels and experiments — not production menu pages.

# Medium

`carousel-tennis.html` is the tennis carousel injection target (see `scripts/build/carousel-configs/tennis.json`). `npm run scaffold:carousel` adds new `carousel-<name>.html` files here.

# Advanced

Paths use `../../Components/` (repo root → `Components/`). Keep depth: files must stay directly under `Website/dev/`.

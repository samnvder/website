# Discounted Enrollment (archived)

Preserved copy of the membership builder **with enrollment discount UI** (strikethrough sticker price + limited-time / offer price).

Use these when building a special-offer or discounted-enrollment page. The normal join page uses the parent-folder builder without discounts.

## Files

| File | Role |
|------|------|
| `Membership Builder frontend.html` | Full builder element (styles + markup) with discount display |
| `membership builder JS.js` | Type-based enrollment discounts ($100 single/couple, $150 family) |
| `membership builder JS-discount-enrollment.js` | Special-offer flat $100 enrollment (summer-style offer) |

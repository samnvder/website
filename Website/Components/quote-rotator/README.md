# SE Quote Rotator — reusable component

A dependency-free rotating quote/testimonial carousel, built 2026-08-20 for the
tour-confirmation page and written to be reused anywhere the site needs rotating
quotes (memberships page, events page, a future testimonials page).

**[`quote-rotator.html`](./quote-rotator.html) is the canonical source.** It is the whole
component in one block: styles + example markup + script.

## The copy-in model (read this before "including" it)

There is no runtime include on this site — pages are pasted into Thrive as
self-contained fragments. So a page **embeds a copy** of the component's style +
script blocks and supplies its own slides. That means:

- **This file is the source you copy from and diff against.** If you improve the
  rotator, improve it *here first*, then re-copy into the pages that embed it.
  (Same one-way discipline as CLAUDE.md's rules mirror — never let a page's copy
  become the only home of a fix.)
- Pages currently embedding a copy:

  | Page | Copy of |
  |---|---|
  | `Website/Pages/Tours (Category)/tour-confirmation/` | styles (in page CSS, `.se-qr` block) + script (inline) |

## Using it

1. Copy the `<style>` block (or merge it into the page's CSS file) and the
   `<script>` block into the page.
2. Add an instance — any number per page (classes only, no ids):

```html
<div class="se-qr" data-interval="6500" role="region" aria-label="Member reviews">
  <button type="button" class="se-qr-arrow se-qr-prev" aria-label="Previous quote">&#8249;</button>
  <button type="button" class="se-qr-arrow se-qr-next" aria-label="Next quote">&#8250;</button>
  <div class="se-qr-track">
    <blockquote class="se-qr-slide" data-interests="Tennis, Pickleball">
      <p class="se-qr-stars" aria-label="5 out of 5 stars">★★★★★</p>
      <p>Verbatim quote text.</p>
      <footer>Reviewer Name<span>Google review</span></footer>
    </blockquote>
    <!-- more slides … -->
  </div>
  <div class="se-qr-dots" role="tablist" aria-label="Choose quote"></div>
</div>
```

3. Options and behavior:
   - `data-interval` — ms between advances (default 6500; `0` disables autoplay).
   - Auto-advance pauses on hover and keyboard focus; arrow keys navigate when
     focused; swipe works on touch; dots are generated by the script.
   - `prefers-reduced-motion` disables both the animation and autoplay.
   - **No-JS / pre-JS state is honest:** slides render as a plain stacked column
     until the script adds `se-qr-ready`. Nothing is display-none'd in source, so
     `guard:capture-markup`, grep, and crawlers all see the quotes.
   - Colors/timing are CSS custom properties on `.se-qr` — override per page.
   - `data-interests` on a slide is inert to the rotator itself; page scripts may
     reorder slides before the rotator script runs (it starts from DOM order).
     The tour-confirmation page uses this to float interest-matched quotes first.

## Content rules

Quotes are **real, verbatim member reviews** — excerpting is fine (contiguous
text, `…` where trimmed), rewording is not. Attribute with the reviewer's public
display name and the platform ("Google review"). Do not use Yelp review text —
Yelp's terms prohibit republishing outside their widgets.

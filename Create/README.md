# Create

## Layman's terms

Templates, concepts, and starting points for building new things. When you want to add a new carousel, button, or page type, you start from here. Think of it as a library of blueprints and examples.

## Medium understanding

Create holds reusable patterns and scaffolds: component templates, game/app concepts, and config-driven generators. Use `Create/components/fun/` for fun components; `Create/games/` for standalone games (e.g. pickleball-pong). Not deployed — used as reference.

## Advanced

- **Structure:** `components/fun/`, `concepts/`, `apps/`, `games/`
- **Scaffold:** `scripts/scaffold/new-carousel.js` uses inline templates in the script, not Create
- **Carousel configs:** `scripts/build/carousel-configs/` drives build

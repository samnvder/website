# Fun Components

## Pickleball Pong

**File:** `Create/games/pickleball-pong.html`

Canonical singular file for the Pickleball Pong game. Self-contained (HTML + CSS + JS). Paste entire block into any page. Do not mix with carousel.

- No carousel
- No external dependencies (fonts loaded via link)
- Scoped to `.pong-fun` wrapper

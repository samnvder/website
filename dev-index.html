🚀 Quick Start Guide

To run this site locally with live reload:

  • Open terminal in this folder
  • Run npm install (first time only)
  • Run npm start to launch the development server
  • The site will open at http://localhost:3000
  • Go to Tour Booking Test Hub to test all 4 booking components

Note: Links currently point to southendclub.com. For full local testing, you'll need to update URLs in each page to use relative paths.

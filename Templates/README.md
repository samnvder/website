# Templates

## Layman's terms

Starter layouts and component patterns for building new pages. When creating a new page or section, you copy from here and customize. Keeps structure consistent across the site.

## Medium understanding

Templates mirror `Components/` structure but are editable starting points, not live components. Use when scaffolding a new page or when the design system doesn't yet have a component. May include Thrive-specific variants. Copy to `Dev/` for actual work.

## Advanced

- **Structure:** Mirrors `Components/` — `Templates/Components/Buttons/` etc.
- **Purpose:** Reference and scaffold; not embedded in live pages
- **Thrive:** May include editor-friendly variants
